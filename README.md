
A simple Spring Boot web application that returns a greeting.


Adithyadev Veliyathuparambil Manoj – 77242

- Java
- Spring Boot 4.1.2
- Spring Web
- Thymeleaf
- Maven

- `/` – returns a plain text greeting
- `/greeting?name=Anna` – HTML page with a personalised greeting and an image

1. Open the project in IntelliJ IDEA.
2. Run `FirstappApplication`.
3. Open `http://localhost:8080/` in a browser.
